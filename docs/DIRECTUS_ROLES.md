# Directus 관리자 역할 운영 안내

이 문서는 Directus 관리 화면에 접근하는 계정의 역할과 운영 범위를 설명합니다. 공개 웹사이트 방문자 계정에는 적용되지 않습니다.

## 역할

### 최고 관리자 (Administrator)

- 소유자 전용 계정입니다.
- 사용자, 역할·정책, 데이터 모델, 프로젝트 설정, 파일, 콘텐츠를 모두 관리합니다.
- 이 역할은 다른 운영자에게 부여하지 않습니다.

### 중간관리자

- 교회정보, 예배 안내, 교회 이야기, 주보·소식, 설교, 교역자 정보를 작성·수정·삭제할 수 있습니다.
- 이미지·문서·영상 파일과 폴더를 관리할 수 있습니다.
- 통계 화면과 활동 기록을 조회할 수 있습니다.
- 보기 관리자 또는 중간관리자 계정을 생성·수정·삭제할 수 있습니다.
- 최고 관리자 계정과 최고 관리자 역할은 조회·수정·삭제·부여할 수 없습니다.
- 데이터 모델, 필드·관계, 역할·정책, 프로젝트 설정은 변경할 수 없습니다.

### 보기 관리자

- 통계와 콘텐츠 목록을 조회할 수 있습니다.
- 콘텐츠, 파일, 사용자, 데이터 모델, 설정을 만들거나 변경하거나 삭제할 수 없습니다.

## 계정 추가 원칙

1. 최고 관리자가 최초 중간관리자를 만듭니다.
2. 중간관리자는 필요할 때 중간관리자 또는 보기 관리자 계정만 만들 수 있습니다.
3. 운영이 끝난 계정은 삭제보다 먼저 비활성화합니다.
4. 공용 계정을 만들지 않고, 각 운영자에게 개인 계정을 부여합니다.

## 적용과 검증

역할 정책 변경 후에는 아래를 확인합니다.

1. 중간관리자로 로그인해 콘텐츠·파일·하위 운영자 계정은 관리할 수 있는지 확인합니다.
2. 같은 계정으로 설정 → 데이터 모델과 설정 → 역할·정책 화면이 열리지 않는지 확인합니다.
3. 보기 관리자로 로그인해 콘텐츠 목록·통계는 보이지만 생성·수정·삭제 기능이 없는지 확인합니다.
4. API에서도 `directus_users`에 최고 관리자 역할을 지정하거나 최고 관리자 계정을 수정하려는 요청이 거부되는지 확인합니다.
