# Directus 콘텐츠 목록 운영

교회 이야기, 주보, 공지, 설교 목록은 공통적으로 최신순 25개씩 열립니다. 이 기본값은 `npm run cms:lists:configure`로 Directus에 저장합니다.

## 콘텐츠 찾기

1. 목록 상단의 검색창에 제목 또는 요약에 포함된 단어를 입력합니다.
2. 필터 버튼에서 `게시 상태`를 선택합니다. 초안, 게시됨, 보관됨을 함께 확인할 수 있습니다.
3. 이야기와 주보는 `분류`도 추가해 두 조건을 함께 적용할 수 있습니다.
4. 목록 아래의 페이지 이동으로 이전·다음 25개 항목을 확인합니다.

검색어와 필터는 함께 사용할 수 있습니다. 결과가 없으면 검색어를 지우거나 필터를 초기화합니다.

## 기본 정렬

| 목록 | 기본 정렬 |
| --- | --- |
| 교회 이야기 | 공개일 최신순 |
| 주보 | 공개일 최신순 |
| 공지 | 공개일 최신순 |
| 설교 | 설교일 최신순 |

각 관리자는 목록 화면에서 일시적으로 정렬, 검색어, 필터를 바꿀 수 있습니다. 기본 프리셋은 새로 접속하는 관리자가 일관된 운영 흐름으로 시작하도록 제공하는 값입니다.

## 주보 올리기

1. `주보`에서 제목, 분류, 공개일을 입력합니다. PDF 주보는 분류를 `주보`로 선택합니다.
2. `주보 파일`에서 PDF·이미지·한글 문서 등 원본 파일을 하나 이상 연결합니다. 파일은 하나씩 추가하며, 필요하면 같은 항목에서 계속 추가합니다.
3. 웹에서 함께 읽어야 하는 예배 시간·중요 일정은 `본문`에도 짧게 적습니다. 방문자가 PDF를 열지 않아도 핵심 정보를 확인할 수 있습니다.
4. 작성 중에는 `게시 상태`를 `초안`으로 두고, 파일과 공개일을 확인한 뒤 `게시됨`을 선택합니다. 지난 주보는 삭제하지 말고 `보관됨`으로 바꿉니다.

공개 화면에서는 PDF를 바로 미리볼 수 있고 원본도 내려받을 수 있습니다. 한글 문서처럼 브라우저에서 미리보기 어려운 파일은 다운로드로 제공합니다.

## 로컬 목록 테스트 데이터

검색·상태·분류·페이지네이션을 확인하기 위한 테스트 데이터가 필요할 때만 다음 명령을 사용합니다. 생성 데이터의 제목은 모두 `[샘플]`으로 시작하며, 일부 게시물에는 Unsplash 테스트 이미지가 연결됩니다.

```bash
SEED_SAMPLE_CONTENT=1 npm run cms:sample-content:seed
```

테스트가 끝난 뒤에는 아래 명령으로 `[샘플]` 제목의 콘텐츠와 `sample-community-` 파일만 제거할 수 있습니다. 실제 운영 콘텐츠에는 영향을 주지 않습니다.

```bash
REMOVE_SAMPLE_CONTENT=1 npm run cms:sample-content:remove
```
