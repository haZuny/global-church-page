# 콘텐츠 모델 초안

교회 이야기와 설교·주보를 나중에 CRUD 화면으로 옮길 때도 목록과 상세 화면의 문장 구조가 흔들리지 않도록 사용하는 공통 필드입니다.

## 교회 이야기

| 필드 | 필수 | 용도 |
| --- | --- | --- |
| `slug` | 필수 | 상세 URL에 사용하는 고유 키 |
| `title` | 필수 | 목록과 상세의 제목. 한 게시물에 하나만 사용 |
| `subtitle` | 필수 | 제목 아래 한 문장 요약(소제목) |
| `body` | 필수 | 본문 문단 배열. 문단·인용·구분 문구 블록으로 구성 |
| `category` | 필수 | 예배, 공동체, 이웃 섬김, 다음 세대 등 |
| `publishedAt` | 필수 | 대표글과 목록 정렬에 사용하는 게시일 |
| `coverImage` | 필수 | 대표 이미지 경로와 대체 텍스트 |
| `gallery` | 선택 | 본문에 추가할 이미지 배열과 설명. 업로드 순서를 유지해 2열(모바일 1열)로 표시 |
| `status` | 필수 | `draft`, `published`, `archived` |

`published` 상태인 글만 방문자 화면에 노출합니다. CRUD 연결 시 대표 영역은 `publishedAt`이 가장 최근인 글 하나를 자동으로 선택하고, 나머지는 같은 카드 구조로 표시합니다. 현재 정적 데모도 이 규칙에 맞춰 최신 글을 대표로 배치했습니다.

## 설교

`slug`, `title`, `subtitle`, `body` 또는 영상 URL, `scripture`, `preacher`, `sermonDate`, `coverImage`, `status`를 사용합니다. 실제 영상과 설교자 정보가 확정되기 전에는 샘플 상태로 표시합니다.

## 주보·소식

`slug`, `title`, `summary`, `category`, `publishedAt`, `document`(사이트 내부 파일), `status`를 사용합니다. 외부 원문 URL을 저장하거나 화면에 노출하지 않습니다.

## 관리자 화면 원칙

- 제목, 소제목, 본문, 대표 이미지, 분류, 게시일을 한 화면에서 미리봅니다.
- 임시 저장·게시·보관 상태를 분리하고 삭제보다 보관을 우선합니다.
- 대표 이미지에는 비율, 용량, 대체 텍스트를 함께 입력합니다.
- 게시일이 없는 글은 대표글 후보가 되지 않게 합니다.
